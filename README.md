## 构建与测试

首次使用先拉取锁定版本的工具链（GBDK-2020 4.5.0，带 SHA-256 校验）：

```bash
tools/get_gbdk.sh
```

一条命令完成生成、全部测试和 ROM 构建：

```bash
./build.sh
```

只构建 ROM（迭代时用）：

```bash
tools/build_rom.sh
```

产物是 `build/gb/sanguo_hjz.gbc`（8 MiB，CGB 专用，MBC5+RAM+电池，128 KiB SRAM），可在 SameBoy 等支持 CGB 的模拟器中运行。

`build.sh` 依次执行：
1. 数据生成：规则表、TECH01 地图与关卡、字库与文本（含对话分页）、曲谱、全屏演员、画像、事件脚本。
2. 主机测试：公式与寻路（附录D 向量 + 独立 Python 参考模型交叉对照，86,228 项）、战斗与 AI（含自对弈复现）、存档（逐字节断电模型）、事件 VM、策略、道具与 AI 策略候选。
3. ROM 构建，以及 bank/RAM 预算硬检查（任何 bank 溢出都会让构建失败）。
4. PyBoy 端到端测试（181 项，全部用真实按键驱动），截图输出到 `build/gb/`。

## 操作（TECH01 试验场）

| 按键 | 作用 |
|---|---|
| 方向键 | 移动光标，镜头自动跟随 |
| A | 选己方单位 → 选终点 → 行动菜单（攻击 / 策略 / 交谈 / 道具 / 交换 / 待命）→ 选目标 → 确认 |
| B | 逐层取消；全屏演出中按 B 跳过；待机时开关敌方危险区 |
| START | 结束回合；开机时继续中断存档 |
| SELECT（标题） | 读取营地存档 |
| SELECT | 写入中断存档（只在我方阶段的空闲状态下有效） |

战役：序战（操演）→ 第一章「桃园」：涿郡破黄巾 → 青州解围（与友军龚景并肩，龚景不能撤退）→ 连续进入破张宝妖术（兵力不补充）→ 汜水关（关羽斩华雄）→ 虎牢关（坚守 12 回合或击退吕布，张飞攻击吕布触发三英战吕布）→ 第二章「群雄」：磐河之战（护送公孙瓒，赵云登场）→ 北海救孔融 → 徐州解围 → 盱眙拒袁术 → 徐州夜袭（护送二夫人出城）→ 连续进入辕门射戟（坚守 8 回合）→ 下邳擒吕布（曹军为友军）→ 第三章「流离」：徐州斩车胄 → 拒刘岱王忠 → 小沛之败（关羽离队）→ 古城会（关羽归队，赵云入队）→ 汝南之战 → 江夏讨张武 → 跃马檀溪（刘备单人突围，徐庶入队）→ 新野破曹仁（徐庶离队）→ 三顾茅庐（诸葛亮入队）→ 本章结局 → 标题。每关开头会说明胜利条件。待机时按 B 显示敌方危险区；走上宝箱格可以拾取宝物。

胜利后得到 500 金，先分配战利品，再进入营地画面：存档 / 军议（必看，看完才能出阵）/ 装备 / 交换（任选两人的任意槽位）/ 商店（左右键切换收货或卖货的人，SELECT 切换买入和卖出）/ 出阵（A 选人，SELECT 前移一位，START 开战；刘备必须出阵）。败北时按 A 重新开始。

道具：刘备带军粮和金疮药，关羽带浊酒，张飞带干粮，简雍带火油罐和祈雨符；敌方刀盾兵也带干粮，受伤后会自己吃。敌方弓手会用火攻。

剧情：开场三人对话；关羽首次攻击敌将时触发单挑；第 3 回合东面出现援军；简雍可以劝降弓手；刘备进村可得到补给。

## 目录

| 路径 | 内容 |
|---|---|
| `src/core/` | 可移植的规则核心：rng、rules、path、battle、ai、save、vm、strategy（主机与 GB 共用同一份代码） |
| `src/gb/` | GB 平台层：WRAM/SRAM 访问器、ROM 网关、输入、地图视图、HUD、全屏演出、对话、音频、主循环 |
| `src/gen/` | 生成的代码（不要手改） |
| `content/` | 规则参数、关卡、文本、曲谱（JSON） |
| `art_src/` | 美术源文件及来源说明 |
| `third_party/` | 字体（Fusion Pixel 12px，OFL）及许可台账 |
| `tools/` | 生成器、编译器、参考模型、构建脚本 |
| `tests/host`、`tests/emu` | 主机测试、PyBoy 测试 |

## 已知限制

- **美术**：地图单位由 BG 合成器绘制（文档 12.2），带调色板重映射、足标、阵营标、移动范围角纹和危险区 X 标。全屏演员和背景是程序生成的占位图；画像只有 8 张 v0.3 概念稿。
- **内容**：做了第一至三章（序战 + 20 关）；第四至第七章（约 30 关）和分支结局还没写。新登场人物除赵云、曹操外没有画像，台词用旁白形式。策略只有地图快演。
- **性能**：一次存档约 0.4 秒（自动存档放在回合横幅期间执行，不占操作时间）。
- **验证**：只在 PyBoy 上测过；SameBoy/Emulicious 交叉验证和真机测试都还没做。
