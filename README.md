设计契约：[三国豪杰传_GBC_最终设计文档_v2.0.md](三国豪杰传_GBC_最终设计文档_v2.0.md)
开发日志（每项发现与修复）：[docs/DEV_LOG.md](docs/DEV_LOG.md)

## 构建与测试

首次使用先拉取锁定版本的工具链（GBDK-2020 4.5.0，带 SHA-256 校验）：

```bash
tools/get_gbdk.sh
```

一条命令完成生成、全部测试和 ROM 构建：

```bash
./build.sh
```

只构建 ROM（迭代时用）：

```bash
tools/build_rom.sh
```

产物是 `build/gb/sanguo_hjz.gbc`（512 KiB，CGB 专用，MBC5+RAM+电池，32 KiB 存档），可在 SameBoy 等支持 CGB 的模拟器中运行，也可以烧进 32 KiB 存档的 MBC5 卡带在真机上玩。

`build.sh` 依次执行：
1. 数据生成：规则表、TECH01 地图与关卡、字库与文本（含对话分页）、曲谱、全屏演员、画像、事件脚本。
2. 主机测试：公式与寻路（附录D 向量 + 独立 Python 参考模型交叉对照，86,228 项）、战斗与 AI（含自对弈复现）、存档（逐字节断电模型）、事件 VM、策略、道具与 AI 策略候选。
3. ROM 构建，以及 bank/RAM 预算硬检查（任何 bank 溢出都会让构建失败）。
4. PyBoy 端到端测试（286 项，全部用真实按键驱动），截图输出到 `build/gb/`。

## 操作（TECH01 试验场）

| 按键 | 作用 |
|---|---|
| 方向键 | 移动光标，镜头自动跟随 |
| A | 选己方单位 → 选终点 → 行动菜单（攻击 / 策略 / 交谈 / 道具 / 交换 / 待命）→ 选目标 → 确认 |
| B | 逐层取消；全屏演出中按 B 跳过；待机时开关敌方危险区 |
| START | 结束回合；开机时继续中断存档 |
| SELECT（标题） | 读取营地存档 |
| SELECT | 写入中断存档（只在我方阶段的空闲状态下有效） |

战役：全七章 51 战加序战。第一章「桃园」（涿郡到虎牢关）→ 第二章「群雄」（徐州）→ 第三章「流离」（依袁、依刘、三顾茅庐）→ 第四章「卧龙」（博望、长坂、赤壁）→ 第五章「荆益」（荆南四郡、入蜀、成都）→ 第六章「汉中」（定军山、汉水、阳平关）→ 第七章「分歧」（水淹七军、麦城）。麦城一战关羽活下来走假想线（北伐中原，结局乙「兴复汉室」），否则走史实线（夷陵、白帝城，结局甲「白帝托孤」）。每关开场写明胜败条件和回合上限。

胜利后先看战果页（关名、历时回合、得金 500），再分配战利品，再进入营地画面：存档 / 军议（必看，看完才能出阵）/ 装备 / 交换（任选两人的任意槽位）/ 商店（左右键切换收货或卖货的人，SELECT 切换买入和卖出）/ 出阵（A 选人，SELECT 前移一位，START 开战；刘备必须出阵）。败北时战果页写明败因：按 A 重打本关，按 SELECT 回到战前营地。

道具：刘备带军粮和金疮药，关羽带浊酒，张飞带干粮，简雍带火油罐和祈雨符；敌方刀盾兵也带干粮，受伤后会自己吃。敌方弓手会用火攻。

剧情：开场三人对话；关羽首次攻击敌将时触发单挑；第 3 回合东面出现援军；简雍可以劝降弓手；刘备进村可得到补给。

## 目录

| 路径 | 内容 |
|---|---|
| `src/core/` | 可移植的规则核心：rng、rules、path、battle、ai、save、vm、strategy（主机与 GB 共用同一份代码） |
| `src/gb/` | GB 平台层：WRAM/SRAM 访问器、ROM 网关、输入、地图视图、HUD、全屏演出、对话、音频、主循环 |
| `src/gen/` | 生成的代码（不要手改） |
| `content/` | 规则参数、关卡、文本、曲谱（JSON） |
| `art_src/` | 美术源文件及来源说明 |
| `third_party/` | 字体（Fusion Pixel 12px，OFL）及许可台账 |
| `tools/` | 生成器、编译器、参考模型、构建脚本 |
| `tests/host`、`tests/emu` | 主机测试、PyBoy 测试 |

## 已知限制

- **美术**：绣像（木刻插图）风格。人物画像、地图小兵、全屏演员来自用 Grok 生成的线稿（`docs/art_brief.md`），用 `tools/import_art.py` 转成 4 色。82 幅画像（已登场人物全部有），11 种兵种小兵，具名人物带将旗。平原、水面、城墙等可拼接的地形是按同样手法手工刻的。
- **内容**：七章全部写完，两条结局线。可选关没做。
- **性能**：一次存档约 0.4 秒（自动存档放在回合横幅期间执行，不占操作时间）。
- **验证**：只在 PyBoy 上测过；SameBoy/Emulicious 交叉验证和真机测试都还没做。
