# 对话页山水画：线稿提示词（交给 Grok）

这些图显示在对话页画像的右边，每一章一幅。游戏里会缩到 80×80 像素、4 个色阶，所以要求和人物画像不一样：**构图要大、元素要少、线条要粗**，细碎的纹理缩小后会糊成一片。

全书七章，每章一幅，另加两条结局线各一幅，共九幅。

## 通用要求

- 正方形 1:1，1024×1024 或更大。
- 纯黑线条加米白纸色，不要彩色，不要灰色晕染。颜色由游戏按青绿山水的颜料来上。
- 画面里只放 3–5 个大的元素，留出大片空白（天空、水面、云雾）。
- 不要人物特写。有人也只是很小的点景人物。
- 不要文字、题款、印章、边框、水印。
- 九幅图最好在同一个对话里连续生成，保证线条粗细和画法一致。

每条提示词已经包含风格说明，整段复制即可。

## 第一章 桃园（涿郡结义、讨伐董卓）

文件名：`scroll_ch1.png`

```
明代木刻版画风格的黑白山水插图，粗黑墨线勾勒轮廓，只用稀疏的平行排线表现阴影，纯黑线条印在米白色素纸上，不要任何彩色，不要灰色晕染，不要渐变，不要边框，不要文字，不要印章，不要水印，正方形构图。画面主题是桃园：近处两三棵盛开的桃树，枝干粗壮弯曲，花朵用简单的圆点表示；桃树下一张摆着香炉的方桌；中景是一间茅草顶的小亭；远处一道低矮的山丘轮廓，天空大片留白。构图简洁，元素少而大，线条粗而干净，缩得很小也能看清。
```
