# 《三国豪杰传》游戏说明

## 按键

| 场合 | 按键 | 作用 |
|---|---|---|
| 地图 | 方向键 | 移动光标 |
| 地图 | A | 选择我方单位 |
| 地图 | B | 显示 / 关闭敌军可攻击范围 |
| 地图 | START | 结束本方回合（先询问，A 确认，B 取消） |
| 地图 | SELECT | 中断存档 |
| 结束回合询问中 | 方向键 | 跳到下一个还没行动的单位 |
| 选择终点、菜单、目标 | A / B | 确认 / 返回上一步 |
| 封面 | A / START / SELECT / B | 新游戏 / 继续中断存档 / 读营地存档 / 看规则说明 |
| 败北画面 | A | 重打本关 |
| 败北画面 | SELECT | 回到战前的营地整备（本关之前有营地时） |

## 胜败条件

- 每一关开场都会显示本关的全部胜利条件和败北条件，包括回合上限。
- 回合上限的意思是：第 N 回合全部结束时还没有取胜，就算败北。
- 刘备撤退必定败北。有些关还有必须保护的人物，会写在败北条件里。

## 会被误会的规则

- **撤退不是阵亡。** 我方武将兵力归零只是本关撤退，下一关可以再出阵。
- **使用道具会消耗行动。** 用过道具的单位本回合不能再攻击或使用策略。
- **天气不符时策略用不出来。** 这时不扣策略值，也不消耗行动。
- **经验满 100 升一级。** 光标停在我方单位上能看到当前经验，攻击后会显示这次得到多少。
- **升级不会回满兵力。** 升级前缺多少兵力，升级后还缺多少：兵力上限加 12，当前兵力也加 12。敌我规则相同，策略值同理。
- **连续战不恢复。** 条件里写着「连续战」的关，兵力（有的还包括士气）从上一关带过来。
- **村庄和城寨格子每回合恢复兵力。** 战场上没有商店，补给要在营地买好。
- **单挑。** 特定武将攻击特定敌将会触发单挑。选择攻击目标时，信息栏出现「可单挑」就是能触发。单挑的结果是剧情决定的。
- **画面淡出变白是在切换场景**，等一下就好。

## 营地

- 出阵前必须先听军议。读档或者败北回营后不用再听一遍。
- 商店里上下移动光标，最下面一行会显示这件东西的效果。
- 战利品：A 交给当前武将，SELECT 卖出，B 舍弃。卖出和舍弃要同一个键按两次才生效，按别的键取消。
- 每名武将最多带 8 件东西。带满了就换一名武将（左右键），或者先卖掉。

## 败北之后

两种选择都会回到这一关出阵前的状态：金钱、道具、兵力、经验都恢复，不会因为失败损失东西。

- **重打本关**：马上用原来的编成再打。
- **回营**：回到战前的营地，可以重新买东西、换装备、调整出阵人选。再次出阵时，以那一刻的状态为新的起点。
